# Anotações do projeto Styne

Esta pasta reúne toda a documentação que antes vivia como comentário dentro
do código-fonte. O código em si (`assets/js`, `assets/css`, `api`,
`database/schema.sql`, `index.html`) ficou limpo, sem anotações — quem
quiser entender o que cada arquivo faz, consulta aqui.

- `database.md` — manual completo do banco de dados: tabelas, relacionamentos e regras de segurança.
- `index.html.md` — mapa das seções do arquivo principal.
- `*.md` restantes — um arquivo por script em `assets/js/`, `assets/css/` e `api/`, com a documentação original de cada um.
